# assets

Đặt logo watermark của bạn ở đây với tên `logo.png` (PNG nền trong, khuyến nghị
64x64 trở lên — script tự scale theo chiều rộng ảnh đích).

Hoặc trỏ sang file khác:

```bash
export WATERMARK_LOGO_PATH=/đường/dẫn/logo.png
```

Repo này **không kèm** logo nào: nhãn hiệu của một công ty không nên được phát
hành kèm theo giấy phép của repo.
