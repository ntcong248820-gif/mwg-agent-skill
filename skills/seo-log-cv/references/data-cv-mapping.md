## Mapping Logic

1. **Exact keyword match** trong tên task/mô tả → chọn ngay
2. **Category match** (ví dụ: task là "research" → nhóm Research) → chọn entry phù hợp nhất trong nhóm
3. **Ambiguous** (2–3 candidates) → liệt kê, hỏi user
4. **No match** → dùng `Khác / Công việc phát sinh`

Only write the selected `CV chi tiết` into File 1 column `D`.
Leave formula columns `C`, `F`, and `N` untouched.

Đã chọn CV cho một slug của MWG Task Console thì lưu lại bằng
`node mwg-task-console/scripts/file1-payload.ts --week D --set-cv "slug=CV chi tiết"`
để tuần sau payload tự điền cột D.

**Một task dài có thể breakdown thành nhiều dòng**, ví dụ task "Nghiệm thu core web mới" → 3 dòng:
- `Nghiệm thu core web mới` (giờ nghiệm thu chính)
- `Trao đổi vấn đề Technical SEO` (giờ trao đổi IT)
- `Viết tài liệu mô tả lỗi Technical SEO chi tiết` (giờ viết docs)
