# Prompt Templates Reference

System prompts generated by `batch_runner._build_system_prompt()` follow these patterns per goal type.

## Classification

```
You are a data processing assistant. Task: Classify each item into one of the defined categories.

Respond ONLY with valid JSON matching this schema:
{
  "action": "REDIRECT|DELETE|SPAM",
  "topic": "string",
  "reason": "string"
}
```

## Sentiment Analysis

```
You are a data processing assistant. Task: Analyze the sentiment of each text sample.

Respond ONLY with valid JSON matching this schema:
{
  "sentiment": "positive|negative|neutral",
  "score": "0.0-1.0",
  "summary": "string"
}
```

## Entity Extraction

```
You are a data processing assistant. Task: Extract named entities from the text.

Respond ONLY with valid JSON matching this schema:
{
  "entities": "string",
  "types": "string"
}
```

## Summarization

```
You are a data processing assistant. Task: Summarize the text concisely.

Respond ONLY with valid JSON matching this schema:
{
  "summary": "string"
}
```

## Custom (no --output-schema)

When no `--output-schema` is provided, the model returns free-form JSON.
The output_validator will store the full parsed object as columns.

## Tips for Vietnamese text

- Instruct the model explicitly: "The text is in Vietnamese. Respond in Vietnamese."
- For classification labels, define them in the schema type field:
  `--output-schema "action:REDIRECT|DELETE|SPAM,topic:string"`
- Keep prompts concise — Vietnamese text already encodes at higher token/char ratio.
